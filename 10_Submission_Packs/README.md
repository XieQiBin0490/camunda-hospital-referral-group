The three packages below are the artefacts submitted to Blackboard, mirrored here so that a reader of
the repository can see exactly what was handed in without opening four separate uploads. Each one is
self-contained: the PDF is the copy that was submitted, the editable source sits beside it.

| --- | --- | --- |

| `UFCEP6-0-3_Presentation/` | UFCEP6-0-3 Presentation, 22 October 2026 | second release, feedback, plan evaluation |

acceptance evaluations) - is not duplicated here: it is `07_Portfolio_Documents/` in this repository,
with `UFCEP4-0-3_Portfolio.pdf` as the exported copy.
