2.  Acceptance test plan: what is in it
=====================================================================

18 cases, each a complete path from the start event to an end state rather than a
single step.

    Section 1  the 18 cases, with the criterion (AC), requirement (REQ) and business
               rule (BR) each case exercises, and its result
    Section 2  preconditions common to every case, and where the cases differ
    Section 3  test data: the start variables and the decisions the human roles take
    Section 4  the actions performed for each case
    Section 5  expected outcome and pass/fail condition for each case, followed by
               what the recorded run actually produced

Identifier scheme: AC-nn is a criterion identifier from the acceptance criteria set
for this release (AC-01 to AC-20, stated in full in the acceptance criteria
evaluation). REQ-nn is the case-study requirement the criterion traces to (REQ-01 to
REQ-44). BR-nn names the business rule the scenario exercises.
